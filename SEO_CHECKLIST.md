## 📋 Robots.txt Rules Explained

```
User-agent: Mediapartners-Google
Allow: /
```
↳ **Critical for AdSense**: Allows Google's ad crawler full access to analyze page context

```
Disallow: /api/
Disallow: /_astro/
Disallow: /cdn-cgi/
```
↳ Blocks crawlers from indexing technical/build directories and API endpoints

```
User-agent: Bytespider, CCBot, GPTBot
Disallow: /
```
↳ Blocks AI scrapers to preserve bandwidth and copyright
