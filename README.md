# 8PayCommission

Independent calculators and analysis for the 8th Pay Commission, salary matrix, pension revisions, DA/HRA, fitment factor, and government pay updates in India.

## Features

- Salary calculator and pay matrix guidance
- Pension, DA, HRA, arrears, and gratuity analysis
- Search-friendly, structured content for Google indexing
- Built with Astro and Cloudflare

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
